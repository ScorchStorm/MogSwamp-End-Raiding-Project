This is a project for the Minecraft MogSwamp SuperFlat Server to better coordinate the raiding of End Cities between large numbers of players. It combines a collaborative online database to track which end cities have been raided  and a progressive improvement algorithm to find an approximate solution to the traveling salesman problem. This program is meant to make the process of end raiding more efficient by reducing travel time and automating the travel planning process, and preventing players from re-visiting end cities that have already been raided.
